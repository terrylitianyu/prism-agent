# Hot Search Skill（市场热点分析）

## Capabilities

| Tool | Description |
|------|-------------|
| get_hot_search_rank | 东财个股人气榜前 N（默认10，可传 top_n 5~30） |
| get_market_news | 财联社电报最新快讯 N 条（默认20，可传 count 5~50） |
| analyze_hot_topics | 基于榜单+快讯提炼热点主题（3~5个），报告落库 |

## 推荐调用流程（市场热点分析）

1. `get_hot_search_rank(top_n=15)` —— 拿到当前最热的个股。
2. `get_market_news(count=20)` —— 拿到最新市场快讯,判断驱动热点的事件。
3. `analyze_hot_topics()` —— 综合分析热点主题(无参数,自动使用已落库的榜单与快讯)。

## 参数与数据约定

- `top_n`/`count` 传了也只会被限制在 5~30 / 5~50 范围内,超出自动截断。
- **缓存与复用**:榜单与快讯落库后,同轮对话内重复调用会自动复用(TTL 缓存),不要重复抓取;数据时效看返回的 `ts` 时间戳。
- **数据时效**:人气榜为抓取时刻快照,盘中会变化;非交易时段为最近交易日数据。
- **降级说明**:东财人气榜不可用时自动降级到百度热搜(仅名称+热度,无股票代码),返回的 `note` 字段会说明;此时想分析具体个股请让用户提供 6 位代码,再走 tech_analysis。
- 快讯内容已截断为 80 字符摘要,给用户展开细节时只需引用标题与时间。

## 输出说明

- 榜单/快讯/分析报告全文都落库,多轮对话可直接复用。
- `analyze_hot_topics` 返回的紧凑摘要(主题名+相关板块+市场总述)用于编排与回复;给用户的最终结论应基于其报告全文组织。
- 用户对某只热门股感兴趣时,引导用户给出代码并用 tech_analysis skill 深入分析。
